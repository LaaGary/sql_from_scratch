SQL syntax and function reference

This reference lists the syntax, functions, error codes, and CLI commands that the engine in this tutorial supports. If you add features of your own, remember to come back and update this page.

Full SELECT syntax

SELECT [DISTINCT] expression [AS alias], ...
 [FROM table [AS alias]
       [ [INNER | LEFT [OUTER]] JOIN table [AS alias] ON condition ] ...]
 [WHERE condition]
 [GROUP BY expression, ...]
 [HAVING condition]
 [ORDER BY expression [ASC | DESC], ...]
 [LIMIT n [OFFSET m]]

MySQL's LIMIT offset, count form is supported as well.

Known limitations

  • No subqueries, UNION, ALTER TABLE, or window functions.
  • RIGHT JOIN / FULL JOIN / USING / NATURAL JOIN are not implemented.
  • No indexes, so every query is a linear scan (JOIN is O(n×m)).
  • Single process; no locks or concurrency control.
  • Every commit rewrites all tables, which gets slow as the data grows.

Further exercises

  1. Add indexes: start with a hash index on the primary key, then take on the B+tree.
  2. Add EXPLAIN: print how a query will execute.
  3. Add VACUUM: rewrite the file and reclaim free pages.
  4. Package the core as an npm package, or build a web-based database editor.
