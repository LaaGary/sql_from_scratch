Chapter 10 / Persistence and transactions

Data survives a restart: pages, journals, and transactions

The database we've built has a fatal flaw: quit the program and the data is gone. This chapter writes the whole database to a file, and does it so that "losing power mid-write won't break it". This is the chapter where the project most resembles a real database.

Why not just JSON.stringify?

The simplest persistence is obviously: on every save, turn the whole database into JSON and write it to a file. That works at small data sizes, but it runs into three problems:

  • You can't change just a part: updating one row still rewrites the entire file.
  • A crash mid-write destroys it: the file may be only half written.
  • It doesn't scale: adding caching, building indexes, or supporting large files later will all be cramped.

Real databases solve this with fixed-size pages. Our format is simple: 4096 bytes per page, page 0 is the file header, followed by the catalog (table schemas) and the heap (data rows).

What the file looks like

Page numberContentsNotes
0headermagic SQLDB01, version, pageCount, catalog location
1…kcatalogthe schema of every table and its heap root page number, as a chain of pages linked by next
k+1…heapeach table's rows, stored in slotted pages and chained by next in the same way

The heap page layout is the classic design from database textbooks: the slot array grows from the front, cells grow from the back, and free space sits in between. Each slot records the cell's offset and length, so deleting or moving a row only touches the slot rather than the whole page.

/**
 * Page Format
 *
 * A database file is not one big JSON blob but fixed-size blocks called pages (4096 bytes here).
 * Fixed-size pages have advantages:
 *   - reads and writes touch only the needed page instead of rewriting the whole file
 *   - caching, transactions, and crash recovery are easier to implement
 *
 * This file only packs data into pages and extracts it back; it never does file I/O,
 * which makes it ideal for unit tests.
 *
 * Page types:
 *   0  file header (magic, version, pageCount, catalog location...)
 *   2  catalog (JSON of table schemas, possibly spanning pages)
 *   3  heap (rows of one table, slotted page)
 *
 * Heap page layout:
 *
 *   +0   type (1 byte) = 3
 *   +4   next page number (u32, 0 means no next page)
 *   +8   slot count (u16)
 *   +10  free offset (u16): bytes used from the end of the page inward
 *   +12  slot array, each slot is 4 bytes: offset (u16) + length (u16)
 *   ...  free space
 *   end   cell data (one JSON row per line), growing backwards
 */

export const PAGE_SIZE = 4096;
export const PAGE_HEADER_SIZE = 12;

export const PAGE_TYPE_CATALOG = 2;
export const PAGE_TYPE_HEAP = 3;

/** How many payload bytes fit in a catalog or free-list page. */
export const DATA_CHUNK_SIZE = PAGE_SIZE - PAGE_HEADER_SIZE;

/** Create an empty heap page. */
export function createHeapPage() {
  const page = Buffer.alloc(PAGE_SIZE);
  page.writeUInt8(PAGE_TYPE_HEAP, 0);
  return page;
}

export function pageType(page) {
  return page.readUInt8(0);
}

export function pageNext(page) {
  return page.readUInt32LE(4);
}

export function setPageNext(page, nextPage) {
  page.writeUInt32LE(nextPage, 4);
}

export function heapSlotCount(page) {
  return page.readUInt16LE(8);
}

export function heapFreeOffset(page) {
  return page.readUInt16LE(10);
}

/** How many bytes remain on this page for cells. */
export function heapFreeBytes(page) {
  return PAGE_SIZE - PAGE_HEADER_SIZE - heapSlotCount(page) * 4 - heapFreeOffset(page);
}

/**
 * Put a cell (a serialized row) into a heap page.
 * Returns false when there is not enough space; the caller must use another page.
 */
export function appendHeapCell(page, cell) {
  if (heapFreeBytes(page) < cell.length + 4) return false;

  const slotCount = heapSlotCount(page);
  const freeOffset = heapFreeOffset(page);
  const cellOffset = PAGE_SIZE - freeOffset - cell.length;

  cell.copy(page, cellOffset);

  const slotOffset = PAGE_HEADER_SIZE + slotCount * 4;
  page.writeUInt16LE(cellOffset, slotOffset);
  page.writeUInt16LE(cell.length, slotOffset + 2);
  page.writeUInt16LE(slotCount + 1, 8);
  page.writeUInt16LE(freeOffset + cell.length, 10);
  return true;
}

/** Read all cells from a heap page (in insertion order). */
export function heapCells(page) {
  const count = heapSlotCount(page);
  const cells = [];
  for (let i = 0; i < count; i++) {
    const slotOffset = PAGE_HEADER_SIZE + i * 4;
    const offset = page.readUInt16LE(slotOffset);
    const length = page.readUInt16LE(slotOffset + 2);
    if (length > 0) cells.push(page.subarray(offset, offset + length));
  }
  return cells;
}

/** Create a data page for the catalog / free list. */
export function createDataPage(type) {
  const page = Buffer.alloc(PAGE_SIZE);
  page.writeUInt8(type, 0);
  return page;
}

export function writeDataChunk(page, chunk) {
  chunk.copy(page, PAGE_HEADER_SIZE);
  page.writeUInt16LE(chunk.length, 8);
}

export function readDataChunk(page) {
  const length = page.readUInt16LE(8);
  return page.subarray(PAGE_HEADER_SIZE, PAGE_HEADER_SIZE + length);
}

// ---------------------------------------------------------------------------
// File header (page 0)
// ---------------------------------------------------------------------------

export const MAGIC = "SQLDB01\n";
export const FORMAT_VERSION = 1;

/**
 * Create the header page.
 * @param {{pageCount:number, catalogRoot:number, catalogLength:number, freeListRoot:number}} info
 */
export function createHeaderPage(info) {
  const page = Buffer.alloc(PAGE_SIZE);
  page.write(MAGIC, 0, "ascii");
  page.writeUInt32LE(FORMAT_VERSION, 8);
  page.writeUInt32LE(PAGE_SIZE, 12);
  page.writeUInt32LE(info.pageCount, 16);
  page.writeUInt32LE(info.catalogRoot, 20);
  page.writeUInt32LE(info.catalogLength, 24);
  page.writeUInt32LE(info.freeListRoot, 28);
  return page;
}

/**
 * Parse the header page; returns null if the file is not ours.
 */
export function parseHeaderPage(page) {
  const magic = page.subarray(0, 8).toString("ascii");
  if (magic !== MAGIC) return null;
  const version = page.readUInt32LE(8);
  if (version !== FORMAT_VERSION) {
    throw new Error("Unsupported database format version: " + version);
  }
  const pageSize = page.readUInt32LE(12);
  if (pageSize !== PAGE_SIZE) {
    throw new Error("Page size mismatch: " + pageSize);
  }
  return {
    pageCount: page.readUInt32LE(16),
    catalogRoot: page.readUInt32LE(20),
    catalogLength: page.readUInt32LE(24),
    freeListRoot: page.readUInt32LE(28),
  };
}

Pager: responsible only for "page n"

Pager has a single responsibility: open the file, read page n, write page n, allocate a new page number. It keeps a page cache and a dirty list recording which pages this transaction changed. Separating "pages" from "data structures" is the key to maintainable database code.

DiskStore: turning a snapshot into pages

DiskStore implements the same interface as MemoryStore: load(), save(), close(). It is responsible for:

  1. Serializing every row of every table to JSON and packing it into the heap page chain.
  2. Writing every schema and each table's root page number into the catalog page chain.
  3. Writing the header page, recording pageCount and the catalog location.
  4. Calling commit(): write the journal first, then the body, then delete the journal.

Free pages aren't written to the file; they're computed on open: take every page in the file, subtract the header, catalog, and heap, and the rest are free. Maintaining one less free list means one less thing that can be corrupted.

src/storage/disk.jsJavaScript · 307 lines · step 10
/**
 * DiskStore: persist the database to disk
 *
 * It has two parts:
 *
 *   Pager  handles "the 4096 bytes of page n" - opening the file, reading/writing pages, allocating new pages
 *   DiskStore handles "how data becomes pages" - catalog, heap, commit
 *
 * File layout (page 0 is the header):
 *
 *   page 0        header: magic, version, pageCount, catalog location
 *   catalog pages JSON of table schemas (may span pages, chained via next)
 *   heap pages    rows of each table (slotted pages, chained via next)
 *
 * Free pages are not written to the file; they are computed on open:
 * all pages in the file minus header / catalog / heap leaves the empty ones.
 * This avoids maintaining a separate free list and removes one more thing that can get corrupted.
 */
import fs from "node:fs";
import {
  PAGE_SIZE, PAGE_HEADER_SIZE, PAGE_TYPE_CATALOG,
  appendHeapCell, createDataPage, createHeaderPage, createHeapPage,
  heapCells, pageNext, parseHeaderPage, readDataChunk, setPageNext, writeDataChunk,
} from "./page.js";
import { recoverJournal, writeJournal } from "./journal.js";

// ---------------------------------------------------------------------------
// Pager: page-level file I/O
// ---------------------------------------------------------------------------

export class Pager {
  /** @param {string} path */
  constructor(path) {
    this.path = path;
    this.fd = null;
    /** @type {Map<number, Buffer>} */
    this.cache = new Map();
    /** @type {Map<number, Buffer>} pages modified by this transaction */
    this.dirty = new Map();
    this.pageCount = 0;
  }

  open() {
    const exists = fs.existsSync(this.path);
    this.fd = fs.openSync(this.path, exists ? "r+" : "w+");
    this.pageCount = exists ? Math.ceil(fs.statSync(this.path).size / PAGE_SIZE) : 0;
  }

  readPage(pageNumber) {
    if (this.cache.has(pageNumber)) return this.cache.get(pageNumber);
    if (pageNumber >= this.pageCount) return Buffer.alloc(PAGE_SIZE);
    const buffer = Buffer.alloc(PAGE_SIZE);
    fs.readSync(this.fd, buffer, 0, PAGE_SIZE, pageNumber * PAGE_SIZE);
    this.cache.set(pageNumber, buffer);
    return buffer;
  }

  writePage(pageNumber, buffer) {
    if (buffer.length !== PAGE_SIZE) {
      throw new Error("Page size must be " + PAGE_SIZE + " bytes");
    }
    this.cache.set(pageNumber, buffer);
    this.dirty.set(pageNumber, buffer);
    if (pageNumber >= this.pageCount) this.pageCount = pageNumber + 1;
  }

  /** Allocate a new page number (does not write contents). */
  allocatePage() {
    const pageNumber = this.pageCount;
    this.pageCount += 1;
    return pageNumber;
  }

  /** Write dirty pages to the file and fsync. */
  flush() {
    for (const [pageNumber, buffer] of this.dirty) {
      fs.writeSync(this.fd, buffer, 0, PAGE_SIZE, pageNumber * PAGE_SIZE);
    }
    fs.fsyncSync(this.fd);
  }

  close() {
    if (this.fd !== null) {
      fs.closeSync(this.fd);
      this.fd = null;
    }
  }
}

// ---------------------------------------------------------------------------
// DiskStore
// ---------------------------------------------------------------------------

export class DiskStore {
  /** @param {string} path database file path */
  constructor(path) {
    if (!path) throw new Error("DiskStore requires a file path");
    this.path = path;
    this.persistent = true;
    this.pager = new Pager(path);
    this.catalog = { version: 1, tables: [] };
    this.catalogPages = [];
    this.freePages = [];
    this.hasData = false;
    this.opened = false;
  }

  /** Open the file, replay the journal if needed, and read the catalog. */
  ensureOpen() {
    if (this.opened) return;

    // Did we crash mid-commit last time? Replay the journal before opening.
    recoverJournal(this.path, PAGE_SIZE);

    this.pager.open();

    if (this.pager.pageCount > 0) {
      const header = parseHeaderPage(this.pager.readPage(0));
      if (header) {
        this.catalogPages = this.readChain(header.catalogRoot);
        const chunks = this.catalogPages.map((pageNumber) => readDataChunk(this.pager.readPage(pageNumber)));
        const payload = Buffer.concat(chunks).toString("utf8");
        this.catalog = JSON.parse(payload);
        this.hasData = true;
        this.freePages = this.computeFreePages();
      }
    }

    this.opened = true;
  }

  /** Read a chain of pages by following next pointers. */
  readChain(rootPage) {
    const pages = [];
    const seen = new Set();
    let pageNumber = rootPage;
    while (pageNumber !== 0) {
      if (seen.has(pageNumber)) throw new Error("Corrupt page chain (cycle detected)");
      seen.add(pageNumber);
      pages.push(pageNumber);
      pageNumber = pageNext(this.pager.readPage(pageNumber));
    }
    return pages;
  }

  /** All pages minus header, catalog, and heap are the free pages. */
  computeFreePages() {
    const used = new Set([0, ...this.catalogPages]);
    for (const table of this.catalog.tables) {
      for (const pageNumber of table.pages) used.add(pageNumber);
    }
    const free = [];
    for (let pageNumber = 1; pageNumber < this.pager.pageCount; pageNumber++) {
      if (!used.has(pageNumber)) free.push(pageNumber);
    }
    return free;
  }

  /** Read all rows of a table. */
  readRows(rootPage) {
    const rows = [];
    let pageNumber = rootPage;
    while (pageNumber !== 0) {
      const page = this.pager.readPage(pageNumber);
      for (const cell of heapCells(page)) {
        rows.push(JSON.parse(cell.toString("utf8")));
      }
      pageNumber = pageNext(page);
    }
    return rows;
  }

  /**
   * Read the whole database. Returns null for a new file.
   * @returns {{version:number, tables:object[]}|null}
   */
  load() {
    this.ensureOpen();
    if (!this.hasData) return null;
    return {
      version: 1,
      tables: this.catalog.tables.map((entry) => ({
        schema: entry.schema,
        nextRowid: entry.nextRowid,
        rows: this.readRows(entry.rootPage),
      })),
    };
  }

  /**
   * Write the entire snapshot to the file.
   *
   * The teaching version rewrites the pages of every table on each commit:
   * simple and hard to get wrong, at the cost of being slow with large data. A real database only rewrites touched pages.
   */
  save(snapshot) {
    this.ensureOpen();

    // Reserve page 0 for the header.
    if (this.pager.pageCount === 0) this.pager.pageCount = 1;

    const oldPages = new Set();
    for (const table of this.catalog.tables) {
      for (const pageNumber of table.pages) oldPages.add(pageNumber);
    }
    for (const pageNumber of this.catalogPages) oldPages.add(pageNumber);

    const freePool = new Set(this.freePages);
    const reused = new Set();
    const allocate = () => {
      if (freePool.size > 0) {
        const pageNumber = freePool.values().next().value;
        freePool.delete(pageNumber);
        reused.add(pageNumber);
        return pageNumber;
      }
      return this.pager.allocatePage();
    };

    // 1. Write each table as a chain of heap pages
    const tables = [];
    for (const table of snapshot.tables) {
      const pages = [];
      let current = null;
      for (const row of table.rows ?? []) {
        const cell = Buffer.from(JSON.stringify(row), "utf8");
        if (!current || !appendHeapCell(current, cell)) {
          current = createHeapPage();
          pages.push(current);
          if (!appendHeapCell(current, cell)) {
            throw new Error("A single row is too large to fit in one page");
          }
        }
      }
      if (pages.length === 0) pages.push(createHeapPage());

      const pageNumbers = pages.map(() => allocate());
      pages.forEach((page, index) => {
        setPageNext(page, index + 1 < pages.length ? pageNumbers[index + 1] : 0);
        this.pager.writePage(pageNumbers[index], page);
      });

      tables.push({
        name: table.schema.name,
        schema: table.schema,
        rootPage: pageNumbers[0],
        pages: pageNumbers,
        nextRowid: table.nextRowid,
        rowCount: (table.rows ?? []).length,
      });
    }

    // 2. Write the catalog JSON as a (possibly multi-page) page chain
    const catalogPayload = Buffer.from(JSON.stringify({ version: 1, tables }), "utf8");
    const chunks = [];
    const chunkSize = PAGE_SIZE - PAGE_HEADER_SIZE;
    for (let offset = 0; offset < catalogPayload.length; offset += chunkSize) {
      chunks.push(catalogPayload.subarray(offset, offset + chunkSize));
    }
    if (chunks.length === 0) chunks.push(Buffer.alloc(0));

    const catalogNumbers = chunks.map(() => allocate());
    chunks.forEach((chunk, index) => {
      const page = createDataPage(PAGE_TYPE_CATALOG);
      writeDataChunk(page, chunk);
      setPageNext(page, index + 1 < chunks.length ? catalogNumbers[index + 1] : 0);
      this.pager.writePage(catalogNumbers[index], page);
    });

    // 3. Header page
    const header = createHeaderPage({
      pageCount: this.pager.pageCount,
      catalogRoot: catalogNumbers[0] ?? 0,
      catalogLength: catalogPayload.length,
      freeListRoot: 0,
    });
    this.pager.writePage(0, header);

    // 4. Update in-memory state and the free page set
    this.catalog = { version: 1, tables };
    this.catalogPages = catalogNumbers;
    this.freePages = [...freePool];
    for (const pageNumber of oldPages) {
      if (!reused.has(pageNumber)) this.freePages.push(pageNumber);
    }
    this.freePages.sort((a, b) => a - b);
    this.hasData = true;

    this.commit();
  }

  /**
   * Commit: write the journal first, then modify the database, then delete the journal.
   * If any step fails, the next open can use the journal to return to a consistent state.
   */
  commit() {
    if (this.pager.dirty.size === 0) return;
    writeJournal(this.path, this.pager.dirty, PAGE_SIZE);
    this.pager.flush();
    fs.unlinkSync(this.path + ".journal");
    this.pager.dirty.clear();
  }

  close() {
    this.pager.close();
  }
}

The transaction journal: a crash won't corrupt anything

The order inside commit() is: write the pages this transaction changes to xxx.journal and fsync; write the COMMIT end marker; then modify the real database file; finally delete the journal.

If the machine dies during commit:

  • the journal has no COMMIT marker → the transaction is treated as if it never happened; drop the journal and the database keeps its old state.
  • the journal has a COMMIT marker → replay (roll forward) every page and the data returns to a consistent state.

Every page carries a CRC32 checksum. This isn't only for catching corruption; it's also how we decide whether a record was written completely.

src/storage/journal.jsJavaScript · 138 lines · step 10
/**
 * Journal and Crash Recovery
 *
 * Consider this: COMMIT must write 5 pages, but the power fails while writing page 3.
 * The file is now half new data and half old data - the database is corrupt.
 *
 * The fix is "write the journal first, then modify the database":
 *
 *   1. write the pages to change (page number + contents) to xxx.journal and fsync
 *   2. write a COMMIT end marker and fsync
 *   3. write the same pages into the real database file
 *   4. delete the journal
 *
 * If it crashes midway:
 *   - no COMMIT marker in the journal -> treat the transaction as not having happened and discard the journal
 *   - COMMIT marker present      -> roll forward all pages to bring the data back to a consistent state
 *
 * Each page carries a CRC32 checksum to avoid reading corrupted data.
 * This is the teaching version; a real database handles more details (LSN, checkpoint, WAL file management).
 */
import fs from "node:fs";

const MAGIC = "JRNL1\n";
const END_PAGE = 0xffffffff;

/** CRC32 lookup table. */
const CRC_TABLE = (() => {
  const table = new Uint32Array(256);
  for (let i = 0; i < 256; i++) {
    let value = i;
    for (let bit = 0; bit < 8; bit++) {
      value = value & 1 ? 0xedb88320 ^ (value >>> 1) : value >>> 1;
    }
    table[i] = value >>> 0;
  }
  return table;
})();

export function crc32(buffer) {
  let crc = 0xffffffff;
  for (const byte of buffer) {
    crc = CRC_TABLE[(crc ^ byte) & 0xff] ^ (crc >>> 8);
  }
  return (crc ^ 0xffffffff) >>> 0;
}

/** Get the journal path for a database file. */
export function journalPath(dbPath) {
  return dbPath + ".journal";
}

/**
 * Write dirty pages to the journal file.
 * @param {string} dbPath
 * @param {Map<number, Buffer>} pages page number -> page contents
 */
export function writeJournal(dbPath, pages, pageSize) {
  const records = [];
  for (const [pageNumber, buffer] of pages) {
    if (buffer.length !== pageSize) {
      throw new Error("Incorrect page size: " + pageNumber);
    }
    const header = Buffer.alloc(12);
    header.writeUInt32LE(pageNumber, 0);
    header.writeUInt32LE(buffer.length, 4);
    header.writeUInt32LE(crc32(buffer), 8);
    records.push(header, buffer);
  }

  const endData = Buffer.from("COMMIT");
  const endHeader = Buffer.alloc(12);
  endHeader.writeUInt32LE(END_PAGE, 0);
  endHeader.writeUInt32LE(endData.length, 4);
  endHeader.writeUInt32LE(crc32(endData), 8);

  const content = Buffer.concat([Buffer.from(MAGIC, "ascii"), ...records, endHeader, endData]);
  const file = fs.openSync(journalPath(dbPath), "w");
  try {
    fs.writeSync(file, content);
    fs.fsyncSync(file);
  } finally {
    fs.closeSync(file);
  }
}

/**
 * If a valid journal exists, replay its pages into the database file, then delete the journal.
 * @returns {boolean} whether a replay happened
 */
export function recoverJournal(dbPath, pageSize) {
  const path = journalPath(dbPath);
  if (!fs.existsSync(path)) return false;

  const content = fs.readFileSync(path);
  if (content.length < MAGIC.length || content.subarray(0, MAGIC.length).toString("ascii") !== MAGIC) {
    fs.unlinkSync(path);
    return false;
  }

  const pages = [];
  let offset = MAGIC.length;
  let committed = false;

  while (offset + 12 <= content.length) {
    const pageNumber = content.readUInt32LE(offset);
    const length = content.readUInt32LE(offset + 4);
    const checksum = content.readUInt32LE(offset + 8);
    offset += 12;
    if (pageNumber === END_PAGE) {
      const endData = content.subarray(offset, offset + length);
      committed = offset + length <= content.length && crc32(endData) === checksum;
      break;
    }
    if (offset + length > content.length) break; // incomplete record
    const data = content.subarray(offset, offset + length);
    if (crc32(data) !== checksum) break; // corrupted contents
    pages.push({ pageNumber, data });
    offset += length;
  }

  if (!committed) {
    // No COMMIT: the transaction never completed; discard the journal and keep the old state.
    fs.unlinkSync(path);
    return false;
  }

  const file = fs.openSync(dbPath, "r+");
  try {
    for (const { pageNumber, data } of pages) {
      fs.writeSync(file, data, 0, data.length, pageNumber * pageSize);
    }
    fs.fsyncSync(file);
  } finally {
    fs.closeSync(file);
  }
  fs.unlinkSync(path);
  return true;
}

Transactions: BEGIN / COMMIT / ROLLBACK

With save() in place, transactions are simple: BEGIN takes a snapshot, ROLLBACK restores it, and only COMMIT actually writes to the file. Every statement during a transaction changes memory only, so other statements see the changes while the file hasn't changed yet.

This is an "optimistic" implementation: no locks, no concurrency control. That's completely sufficient for a single program, but multiple processes opening the same file at once would need more machinery (file locks, MVCC, WAL LSNs). That's a direction well worth exploring further.

src/database.js: add transactions and autocommit

  /**

      /** @type {Map<string, Table>} key is the lowercase table name */
      this.tables = new Map();
      this.closed = false;
      this.inTransaction = false;
      this.transactionBackup = null;
    }
  
    /**
     * Open a database: create a Database and load existing data from the store.
     * @param {{load:Function, save:Function, close?:Function}} [store]
     */
    static open(store = new MemoryStore()) {
      const db = new Database({ store });
      const snapshot = store.load();
      if (snapshot) db.loadSnapshot(snapshot);
      return db;
    }
  
    /** Find a table by name (case-insensitive); returns undefined if not found. */
    findTable(name) {
      return this.tables.get(String(name).toLowerCase());
    }
  
    /** Find a table by name; throws if not found. */
    getTable(name) {
      const table = this.findTable(name);
      if (!table) {
        throw new SqlError("Table does not exist: " + name, {
          code: "SCHEMA_ERROR",
          hint: this.listTables().length > 0 ? "Existing tables: " + this.listTables().join(", ") : "There are no tables yet",
        });
      }
      return table;
    }
  
    hasTable(name) {
      return this.tables.has(String(name).toLowerCase());
    }
  
    listTables() {
      return [...this.tables.values()].map((table) => table.name);
    }
  
    /** Create a table (the schema is produced by schema.js). */
    createTable(schema) {
      if (this.hasTable(schema.name)) {
        throw new SqlError("Table already exists: " + schema.name, { code: "SCHEMA_ERROR" });
      }
      const table = new Table(schema);
      this.tables.set(schema.name.toLowerCase(), table);
      return table;
    }
  
    /** Drop a table; returns whether anything was actually dropped. */
    dropTable(name) {
      return this.tables.delete(String(name).toLowerCase());
    }
  
    /** Export a snapshot of the whole database (plain data, JSON-serializable). */
    snapshot() {
      return {
        version: SNAPSHOT_VERSION,
        tables: [...this.tables.values()].map((table) => table.toJSON()),
      };
    }
  
    /** Restore the whole database from a snapshot. */
    loadSnapshot(snapshot) {
      if (!snapshot || !Array.isArray(snapshot.tables)) {
        throw new SqlError("Invalid database file format", { code: "STORAGE_ERROR" });
      }
      this.tables.clear();
      for (const data of snapshot.tables) {
        const table = new Table(data.schema, { rows: data.rows, nextRowid: data.nextRowid });
        this.tables.set(table.name.toLowerCase(), table);
      }
    }
  
    /** Write the current state back to the storage backend. */
    save() {
      this.store.save(this.snapshot());
    }
  
    /**
     * Execute a SQL string (possibly multiple statements) and return an array of results.
     * @param {string} sql
     * @returns {object[]}
     */
    exec(sql) {
      const statements = parseScript(sql);
      const results = [];
  
      for (const ast of statements) {
        // Transaction control statements are handled by Database itself, not the executor.
        if (ast.type === "begin") {
          if (this.inTransaction) {
            throw new SqlError("Already in a transaction; cannot BEGIN again", { code: "TRANSACTION_ERROR" });
          }
          this.inTransaction = true;
          this.transactionBackup = this.snapshot();
          results.push(command("transaction started"));
          continue;
        }
        if (ast.type === "commit") {
          if (!this.inTransaction) {
            throw new SqlError("No transaction in progress to COMMIT", { code: "TRANSACTION_ERROR" });
          }
          this.save();
          this.inTransaction = false;
          this.transactionBackup = null;
          results.push(command("transaction committed"));
          continue;
        }
        if (ast.type === "rollback") {
          if (!this.inTransaction) {
            throw new SqlError("No transaction in progress to ROLLBACK", { code: "TRANSACTION_ERROR" });
          }
          this.loadSnapshot(this.transactionBackup);
          this.inTransaction = false;
          this.transactionBackup = null;
          results.push(command("transaction rolled back"));
          continue;
        }
  
        // Each statement is all-or-nothing: take a snapshot first, restore it on failure.
        const before = this.snapshot();
        try {
          results.push(execute(this, ast));
          // Autocommit: not every store needs it (the in-memory one does not).
          if (!this.inTransaction && this.store.persistent) this.save();
        } catch (error) {
          this.loadSnapshot(before);
          throw error;
        }
      }
      return results;
    }
  
    /**
     * Execute a single statement and return the first result (handy for tests and small tools).
     * @param {string} sql
     */
    query(sql) {
      return this.exec(sql)[0];
    }
  
    /** Close the database: save first, then close the store. Uncommitted transactions are discarded. */
    close() {
      if (this.closed) return;
      if (this.inTransaction) {
        // Transactions without COMMIT are discarded (ROLLBACK semantics).
        this.loadSnapshot(this.transactionBackup);
        this.inTransaction = false;
        this.transactionBackup = null;
      }
      this.save();
      this.store.close?.();
      this.closed = true;
    }
  }

Verification: simulating a power loss

The test does this:

  1. Create a database, write data, and close it.
  2. Write a journal by hand, then truncate it, simulating "the journal was only half written".
  3. Reopen the database and confirm the journal was discarded and the database is unchanged.
  4. Write a complete journal, reopen, and confirm the pages are replayed.

test("journal: a valid journal is replayed", () => {
  const filePath = file("journal.db");
  fs.writeFileSync(filePath, Buffer.alloc(PAGE_SIZE * 2));
  const page = Buffer.alloc(PAGE_SIZE);
  page.write("NEWDATA");
  writeJournal(filePath, new Map([[1, page]]), PAGE_SIZE);
  assert.ok(fs.existsSync(journalPath(filePath)));

  assert.equal(recoverJournal(filePath, PAGE_SIZE), true);
  assert.equal(fs.existsSync(journalPath(filePath)), false);
  assert.equal(fs.readFileSync(filePath).subarray(PAGE_SIZE, PAGE_SIZE + 7).toString(), "NEWDATA");
});

test("journal: a journal without COMMIT is discarded and the database stays as it was", () => {
  const filePath = file("journal-torn.db");
  fs.writeFileSync(filePath, Buffer.alloc(PAGE_SIZE * 2));
  const page = Buffer.alloc(PAGE_SIZE);
  page.write("NEWDATA");
  writeJournal(filePath, new Map([[1, page]]), PAGE_SIZE);

  // simulate "power loss mid-write": truncate part of the journal
  const journal = fs.readFileSync(journalPath(filePath));
  fs.writeFileSync(journalPath(filePath), journal.subarray(0, journal.length - 20));

  assert.equal(recoverJournal(filePath, PAGE_SIZE), false);
  assert.equal(fs.existsSync(journalPath(filePath)), false);
  const pageAfter = fs.readFileSync(filePath).subarray(PAGE_SIZE, PAGE_SIZE + 7);
  assert.deepEqual([...pageAfter], [0, 0, 0, 0, 0, 0, 0]);
});

Chapter recap

  • A database file is made of 4096-byte pages: header, catalog, heap.
  • A slotted page lets rows grow from the end of the page while slots grow from the front.
  • The journal is written before commit and replayed after a crash; without a COMMIT marker it's discarded.
  • Transactions are implemented with snapshots: BEGIN snapshots, ROLLBACK restores, COMMIT writes the file.

Exercises

  1. Implement VACUUM: rewrite every table into contiguous pages to shrink the file.
  2. Build a B+tree index for the PRIMARY KEY so WHERE id = ? doesn't scan the whole table.
  3. Add a .backup <file> command that copies a consistent backup using the existing page format.

Chapter glossary

Pager
The module that reads and writes fixed-size pages.
Slotted page
A page layout where a slot array points at the actual data, making deletes and moves cheap.
Journal / WAL
Write changes to a log first, then apply them to the main file; used for crash recovery.
Roll forward
Replay committed changes from the log so the data returns to a consistent state.
Autocommit
Every statement automatically becomes a transaction.
