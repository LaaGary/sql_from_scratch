Chapter 06 / SELECT pipeline

Your first real query: the SELECT execution pipeline

In the first five chapters we built tokens, a syntax tree, the value system, and tables — but we still can't query anything. This chapter connects the last pieces: the expression evaluator, the SELECT pipeline, write statements, and a CLI that can print tables. When you're done, you'll have a SQL database you can actually use.

The query pipeline: six stations of a SELECT

FROM     find the table, wrap each row as a "source list"
JOIN     attach rows from other tables (Chapter 9)
WHERE    keep only rows whose condition is TRUE
GROUP BY group rows (Chapter 7)
SELECT   compute the output columns
DISTINCT drop duplicate output rows
ORDER BY sort
LIMIT    take the first n rows

The executor doesn't do all of this at once; it transforms the data one stage at a time. This style (a simplified version of what database textbooks call the volcano model) lets you test each stage on its own, and makes optimizations easy to insert later: for example, adding a "look up a single row by primary key" shortcut right after FROM without touching any later stage.

What does a "row" look like at runtime?

A row during query execution isn't a single object; it's a source list: each source carries an alias, a table schema, and values. After a JOIN there are two or more sources, so we need to remember which table each value came from. 

[
  { alias: "b", table: booksSchema,   values: { id: 1, title: "JS" } },
  { alias: "a", table: authorsSchema, values: { id: 7, name: "Alice" } }
]

Why not merge the two tables into one object? Because after a JOIN there are often columns with the same name (both sides have id), and merging would clobber one of them. Only a source list can tell b.id from a.id, and can report "add an alias" when a column name is ambiguous.

Expression evaluation: turning an AST into a value

The evaluator is one big switch: a literal returns itself, a column looks itself up in the source list, a binary node dispatches on its operator, and a call invokes a function. A few implementation details are worth noting:

  • AND / OR must short-circuit: FALSE AND x doesn't need to evaluate x. But because SQL has three-valued logic, the short-circuit rule has to account for UNKNOWN: NULL AND FALSE is still FALSE.
  • NULL propagates through arithmetic: NULL + 1 is NULL; division by zero also returns NULL (rather than raising, which is SQLite's behavior).
  • Ambiguous column names must raise: if two sources have a same-named column and no alias disambiguates them, evaluateColumn throws AMBIGUOUS_COLUMN.

/**
 * Expression Evaluation
 *
 * WHERE conditions, SELECT columns, UPDATE values... are all expressions. This file turns
 * an AST expression into a value.
 *
 * A "row" looks like this during evaluation:
 *
 *   [
 *     { alias: "b", table: schema, values: { id: 1, title: "JS" } },
 *     { alias: "a", table: schema, values: { id: 7, name: "Alice" } }
 *   ]
 *
 * Why not just merge two tables into one object? Because JOIN can produce columns with the same name,
 * and a "source list" is needed to resolve b.id vs. a.id and to report ambiguous column names.
 *
 * This chapter supports: comparison, arithmetic, AND/OR/NOT, LIKE, IN, BETWEEN, IS NULL,
 * string concatenation, and common scalar functions. Aggregate functions (COUNT/SUM...) come in the next chapter.
 */
import { SqlError } from "../errors.js";
import {
  and3, compare, displayValue, isNull, likeMatch, not3, or3,
  toNumber, toText, truthy, typeOf,
} from "../values.js";

/** Aggregate function names; these need a group of rows, not a single row. */
export const AGGREGATE_FUNCTIONS = new Set(["COUNT", "SUM", "AVG", "MIN", "MAX"]);

/** Scalar functions: one value in, one value out. */
const SCALAR_FUNCTIONS = new Map([
  ["UPPER", { min: 1, max: 1, fn: (args) => (isNull(args[0]) ? null : toText(args[0]).toUpperCase()) }],
  ["LOWER", { min: 1, max: 1, fn: (args) => (isNull(args[0]) ? null : toText(args[0]).toLowerCase()) }],
  ["LENGTH", { min: 1, max: 1, fn: (args) => (isNull(args[0]) ? null : toText(args[0]).length) }],
  ["TRIM", { min: 1, max: 1, fn: (args) => (isNull(args[0]) ? null : toText(args[0]).trim()) }],
  ["ABS", { min: 1, max: 1, fn: (args) => (isNull(args[0]) ? null : Math.abs(requireNumber("ABS", args[0]))) }],
  ["ROUND", { min: 1, max: 2, fn: (args) => (isNull(args[0]) ? null : round(requireNumber("ROUND", args[0]), args[1] ?? 0)) }],
  ["COALESCE", { min: 1, max: Infinity, fn: (args) => args.find((value) => !isNull(value)) ?? null }],
  ["IFNULL", { min: 2, max: 2, fn: (args) => (isNull(args[0]) ? args[1] : args[0]) }],
  ["TYPEOF", { min: 1, max: 1, fn: (args) => typeOf(args[0]) }],
  ["REPLACE", {
    min: 3,
    max: 3,
    fn: (args) => {
      if (args.some(isNull)) return null;
      return toText(args[0]).split(toText(args[1])).join(toText(args[2]));
    },
  }],
  ["SUBSTR", {
    min: 2,
    max: 3,
    fn: (args) => {
      if (isNull(args[0])) return null;
      const text = toText(args[0]);
      const start = requireNumber("SUBSTR", args[1]);
      // SQL's SUBSTR is 1-based
      if (args.length === 3) {
        const length = requireNumber("SUBSTR", args[2]);
        return text.slice(start - 1, start - 1 + length);
      }
      return text.slice(start - 1);
    },
  }],
]);

function round(number, digits) {
  const places = digits === null || digits === undefined ? 0 : Number(digits);
  const factor = 10 ** Math.trunc(places);
  return Math.round(number * factor) / factor;
}

function requireNumber(fnName, value) {
  const number = toNumber(value);
  if (number === null) {
    throw new SqlError(fnName + " expects a number, got: " + displayValue(value), { code: "EXECUTION_ERROR" });
  }
  return number;
}

/**
 * Evaluate an expression to a value.
 *
 * @param {object} expr AST expression
 * @param {Array} row source list (see the file header); empty array when there is no FROM
 * @param {{aggregate?: (expr: object) => unknown}} [state] evaluator for aggregate functions
 * @returns {unknown}
 */
export function evaluate(expr, row, state = {}) {
  switch (expr.type) {
    case "literal":
      return normalizeLiteral(expr.value);

    case "column":
      return evaluateColumn(expr, row);

    case "star":
      throw new SqlError("Asterisk * may only appear in a SELECT column list", { code: "EXECUTION_ERROR" });

    case "unary": {
      if (expr.op === "NOT") {
        const value = evaluate(expr.expr, row, state);
        if (isNull(value)) return null;
        return !truthy(value);
      }
      const value = evaluate(expr.expr, row, state);
      if (isNull(value)) return null;
      const number = toNumber(value);
      if (number === null) {
        throw new SqlError("Unary minus expects a number, got: " + displayValue(value), { code: "EXECUTION_ERROR" });
      }
      return expr.op === "-" ? -number : number;
    }

    case "binary":
      return evaluateBinary(expr, row, state);

    case "isnull": {
      const value = evaluate(expr.expr, row, state);
      const result = isNull(value);
      return expr.not ? !result : result;
    }

    case "like": {
      const value = evaluate(expr.expr, row, state);
      const pattern = evaluate(expr.pattern, row, state);
      const matched = likeMatch(value, pattern);
      if (matched === null) return null;
      return expr.not ? !matched : matched;
    }

    case "in": {
      const value = evaluate(expr.expr, row, state);
      if (isNull(value)) return null;
      let sawNull = false;
      for (const item of expr.list) {
        const candidate = evaluate(item, row, state);
        if (isNull(candidate)) {
          sawNull = true;
          continue;
        }
        if (compare("=", value, candidate) === true) {
          return expr.not ? false : true;
        }
      }
      if (sawNull) return null; // unknown
      return expr.not ? true : false;
    }

    case "between": {
      const value = evaluate(expr.expr, row, state);
      const low = evaluate(expr.low, row, state);
      const high = evaluate(expr.high, row, state);
      const result = and3(compare(">=", value, low), compare("<=", value, high));
      if (result === null) return null;
      return expr.not ? !result : result;
    }

    case "call": {
      const name = expr.name.toUpperCase();
      if (AGGREGATE_FUNCTIONS.has(name)) {
        if (!state.aggregate) {
          throw new SqlError(
            "Aggregate function " + name + " requires GROUP BY or must apply to the whole table",
            { code: "EXECUTION_ERROR" }
          );
        }
        return state.aggregate(expr);
      }
      return evaluateCall(expr, row, state);
    }

    default:
      throw new SqlError("Cannot evaluate expression: " + expr.type, { code: "INTERNAL_ERROR" });
  }
}

function normalizeLiteral(value) {
  if (typeof value === "boolean") return value ? 1 : 0;
  return value ?? null;
}

/** Look up a value by column name; report a clear error if it is ambiguous or missing. */
export function evaluateColumn(expr, row) {
  const wanted = String(expr.name).toLowerCase();
  const matches = [];

  for (const source of row) {
    if (expr.table) {
      if (String(source.alias).toLowerCase() !== String(expr.table).toLowerCase()) continue;
    }
    const column = source.table.columns.find((c) => c.name.toLowerCase() === wanted);
    if (!column) continue;
    matches.push({
      source,
      value: source.values ? source.values[column.name] : null,
    });
  }

  if (matches.length === 0) {
    const hint = row.length > 0
      ? "Available columns: " + row.map((source) => source.alias + "." + source.table.columns.map((c) => c.name).join(", ")).join(" | ")
      : "This query has no FROM, so columns cannot be referenced";
    throw new SqlError(
      "Column not found: " + (expr.table ? expr.table + "." : "") + expr.name,
      { code: "UNKNOWN_COLUMN", hint }
    );
  }
  if (matches.length > 1) {
    throw new SqlError(
      "Ambiguous column: " + expr.name + " exists in " + matches.map((m) => m.source.alias).join(", "),
      { code: "AMBIGUOUS_COLUMN", hint: "Add a table alias, e.g. b." + expr.name }
    );
  }
  return matches[0].value;
}

function evaluateBinary(expr, row, state) {
  // AND / OR short-circuit: once the left side is false / true, the right side is not evaluated.
  if (expr.op === "AND" || expr.op === "OR") {
    const left = toBoolean3(evaluate(expr.left, row, state));
    if (expr.op === "AND" && left === false) return false;
    if (expr.op === "OR" && left === true) return true;
    const right = toBoolean3(evaluate(expr.right, row, state));
    return expr.op === "AND" ? and3(left, right) : or3(left, right);
  }

  const left = evaluate(expr.left, row, state);
  const right = evaluate(expr.right, row, state);

  switch (expr.op) {
    case "=":
    case "==":
    case "!=":
    case "<>":
    case "<":
    case "<=":
    case ">":
    case ">=":
      return compare(expr.op, left, right);
    case "||": {
      if (isNull(left) || isNull(right)) return null;
      return toText(left) + toText(right);
    }
    default:
      return arithmetic(expr.op, left, right);
  }
}

/** Convert any value to true / false / null for three-valued logic. */
function toBoolean3(value) {
  if (isNull(value)) return null;
  return truthy(value);
}

/** Arithmetic: NULL propagates; strings are coerced to numbers. */
function arithmetic(op, left, right) {
  if (isNull(left) || isNull(right)) return null;
  const a = toNumber(left);
  const b = toNumber(right);
  if (a === null || b === null) {
    throw new SqlError(
      "Arithmetic requires numbers, got: " + displayValue(left) + " " + op + " " + displayValue(right),
      { code: "EXECUTION_ERROR" }
    );
  }
  switch (op) {
    case "+":
      return a + b;
    case "-":
      return a - b;
    case "*":
      return a * b;
    case "/":
      if (b === 0) return null; // division by zero -> NULL (same as SQLite)
      // Division in this engine is always real division: 10 / 4 yields 2.5.
      // (Some databases do integer division and yield 2; we chose the less surprising behavior for beginners.)
      return a / b;
    case "%":
      if (b === 0) return null;
      return a % b;
    default:
      throw new SqlError("Unsupported operator: " + op, { code: "EXECUTION_ERROR" });
  }
}

function evaluateCall(expr, row, state) {
  const name = expr.name.toUpperCase();
  const definition = SCALAR_FUNCTIONS.get(name);
  if (!definition) {
    throw new SqlError("Unsupported function: " + name, {
      code: "EXECUTION_ERROR",
      hint: "Supported functions: " + [...SCALAR_FUNCTIONS.keys()].join(", ") + ", plus aggregate functions " + [...AGGREGATE_FUNCTIONS].join(", "),
    });
  }
  if (expr.star) {
    throw new SqlError(name + " does not accept *", { code: "EXECUTION_ERROR" });
  }
  if (expr.distinct) {
    throw new SqlError("Only aggregate functions support DISTINCT", { code: "EXECUTION_ERROR" });
  }
  if (expr.args.length < definition.min || expr.args.length > definition.max) {
    const expected = definition.min === definition.max ? String(definition.min) : definition.min + "~" + definition.max;
    throw new SqlError(name + " expects " + expected + " arguments, got " + expr.args.length, {
      code: "EXECUTION_ERROR",
    });
  }
  const args = expr.args.map((arg) => evaluate(arg, row, state));
  return definition.fn(args);
}

/**
 * Column names for query results.
 * Use the alias if present; otherwise print the expression back as SQL-like text.
 */
export function columnLabel(expr) {
  switch (expr.type) {
    case "column":
      return expr.name;
    case "literal":
      if (expr.value === null) return "NULL";
      if (typeof expr.value === "string") return "'" + expr.value.replace(/'/g, "''") + "'";
      return String(expr.value);
    case "unary":
      return expr.op === "NOT" ? "NOT " + columnLabel(expr.expr) : expr.op + columnLabel(expr.expr);
    case "binary":
      return columnLabel(expr.left) + " " + expr.op + " " + columnLabel(expr.right);
    case "isnull":
      return columnLabel(expr.expr) + (expr.not ? " IS NOT NULL" : " IS NULL");
    case "like":
      return columnLabel(expr.expr) + (expr.not ? " NOT LIKE " : " LIKE ") + columnLabel(expr.pattern);
    case "in":
      return columnLabel(expr.expr) + (expr.not ? " NOT IN" : " IN") + " (" + expr.list.map(columnLabel).join(", ") + ")";
    case "between":
      return (
        columnLabel(expr.expr) + (expr.not ? " NOT BETWEEN " : " BETWEEN ") +
        columnLabel(expr.low) + " AND " + columnLabel(expr.high)
      );
    case "call":
      return expr.name + "(" + (expr.star ? "*" : expr.args.map(columnLabel).join(", ")) + ")";
    default:
      return "expr";
  }
}

/** Whether this expression (including descendants) contains an aggregate function. */
export function containsAggregate(expr) {
  if (!expr || typeof expr !== "object") return false;
  if (expr.type === "call" && AGGREGATE_FUNCTIONS.has(expr.name.toUpperCase())) return true;
  for (const value of Object.values(expr)) {
    if (Array.isArray(value)) {
      if (value.some((item) => containsAggregate(item))) return true;
    } else if (value && typeof value === "object" && containsAggregate(value)) {
      return true;
    }
  }
  return false;
}

Implementing the SELECT pipeline

executeSelect builds the sources, scans the table, then pushes every row through WHERE, projection, DISTINCT, sorting, and LIMIT in that order. This version has no JOIN or grouping yet, so those statements produce an explicit "added in Chapter 7 / 9" error — a good error message tells you the next step, instead of just saying "not supported".

src/engine/query.jsJavaScript · 217 lines · step 6
/**
 * SELECT Execution Pipeline
 *
 * A SELECT goes through these stages in order:
 *
 *   FROM     find the table and wrap each row as a "source list"
 *   JOIN     attach rows from other tables (chapter 9)
 *   WHERE    keep only rows whose condition is TRUE
 *   GROUP BY groups rows and computes aggregates (chapter 7)
 *   HAVING   filter groups
 *   SELECT   compute the output columns
 *   DISTINCT remove duplicate output rows
 *   ORDER BY sort
 *   LIMIT    take the first N rows
 *
 * This chapter completes FROM / WHERE / SELECT / DISTINCT / ORDER BY / LIMIT.
 * Queries without FROM (e.g. SELECT 1 + 1) must work too, so the source list may be empty.
 */
import { SqlError } from "../errors.js";
import { columnLabel, containsAggregate, evaluate } from "./expr.js";
import { compareValues, groupKey, isNull, truthy, typeOf } from "../values.js";

/**
 * Execute SELECT and return the query result.
 * @param {import("../database.js").Database} db
 * @param {object} ast the select node from the parser
 */
export function executeSelect(db, ast) {
  if (ast.joins.length > 0) {
    throw new SqlError("JOIN is not implemented yet (arrives in chapter 9)", { code: "NOT_SUPPORTED" });
  }
  if (ast.groupBy.length > 0 || ast.having || ast.columns.some((item) => containsAggregate(item.expr))) {
    throw new SqlError("GROUP BY / aggregate functions are not implemented yet (arrive in chapter 7)", { code: "NOT_SUPPORTED" });
  }

  const sources = buildSources(db, ast);
  const rows = scan(db, sources);
  const filtered = applyWhere(ast, rows);
  const defs = buildProjection(ast, sources);
  const labels = defs.map((def) => def.label);
  const state = {};

  let projected = filtered.map((row) => ({
    row,
    labels,
    values: projectRow(defs, row, state),
  }));

  if (ast.distinct) {
    projected = dedupe(projected);
  }

  if (ast.orderBy.length > 0) {
    projected = sortRows(projected, ast.orderBy, state);
  }

  projected = applyLimit(projected, ast);

  return {
    type: "select",
    columns: describeColumns(defs, projected),
    rows: projected.map((item) => item.values),
    rowCount: projected.length,
  };
}

/** Build the source list: [{ alias, table }]. */
function buildSources(db, ast) {
  if (!ast.from) return [];
  const alias = ast.from.alias ?? ast.from.name;
  const table = db.getTable(ast.from.name);
  return [{ alias, table }];
}

/** Scan the table, turning each row into a source entry. */
function* scan(db, sources) {
  if (sources.length === 0) {
    yield [];
    return;
  }
  const [source] = sources;
  for (const values of source.table.all()) {
    yield [{ alias: source.alias, table: source.table, values }];
  }
}

function applyWhere(ast, rows) {
  if (!ast.where) return [...rows];
  const result = [];
  for (const row of rows) {
    const value = evaluate(ast.where, row, {});
    // Three-valued logic: keep only TRUE (NULL / UNKNOWN count as not satisfied)
    if (truthy(value)) result.push(row);
  }
  return result;
}

/**
 * Determine the output columns. SELECT * expands into multiple column definitions;
 * other expressions use their alias or a derived name.
 */
function buildProjection(ast, sources) {
  const defs = [];
  for (const item of ast.columns) {
    if (item.expr.type === "star") {
      const targets = item.expr.table
        ? sources.filter((source) => source.alias.toLowerCase() === item.expr.table.toLowerCase())
        : sources;
      if (targets.length === 0) {
        throw new SqlError("Table not found: " + (item.expr.table ?? "(no FROM)"), {
          code: "SCHEMA_ERROR",
          hint: "SELECT * requires FROM.",
        });
      }
      for (const source of targets) {
        for (const column of source.table.columns) {
          defs.push({
            kind: "source-column",
            alias: source.alias,
            columnName: column.name,
            label: column.name,
          });
        }
      }
      continue;
    }
    defs.push({
      kind: "expression",
      expr: item.expr,
      label: item.alias ?? columnLabel(item.expr),
    });
  }
  if (defs.length === 0) {
    throw new SqlError("SELECT requires at least one column", { code: "SYNTAX_ERROR" });
  }
  return defs;
}

function projectRow(defs, row, state) {
  return defs.map((def) => {
    if (def.kind === "source-column") {
      const source = row.find((item) => item.alias === def.alias);
      if (!source || !source.values) return null;
      return source.values[def.columnName] ?? null;
    }
    return evaluate(def.expr, row, state);
  });
}

/** Output column name and type (the type comes from the first non-NULL value). */
function describeColumns(defs, projected) {
  return defs.map((def, index) => {
    let type = "null";
    for (const item of projected) {
      if (!isNull(item.values[index])) {
        type = typeOf(item.values[index]);
        break;
      }
    }
    return { name: def.label, type };
  });
}

function dedupe(projected) {
  const seen = new Set();
  const result = [];
  for (const item of projected) {
    const key = groupKey(item.values);
    if (seen.has(key)) continue;
    seen.add(key);
    result.push(item);
  }
  return result;
}

/**
 * Sorting. ORDER BY accepts source columns or output column aliases:
 *
 *   SELECT price * 2 AS double FROM books ORDER BY double DESC
 */
function sortRows(projected, orderBy, state) {
  const decorated = projected.map((item) => ({
    ...item,
    keys: orderBy.map((order) => orderValue(order.expr, item, state)),
  }));

  decorated.sort((left, right) => {
    for (let i = 0; i < orderBy.length; i++) {
      const direction = orderBy[i].direction === "desc" ? -1 : 1;
      const compared = compareValues(left.keys[i], right.keys[i]);
      if (compared !== 0) return compared * direction;
    }
    return 0;
  });

  return decorated;
}

function orderValue(expr, item, state) {
  // Check for an output column alias first (SQL allows aliases in ORDER BY).
  if (expr.type === "column" && !expr.table) {
    const index = item.labels.findIndex(
      (label) => label.toLowerCase() === expr.name.toLowerCase()
    );
    if (index >= 0) return item.values[index];
  }
  return evaluate(expr, item.row, state);
}

function applyLimit(projected, ast) {
  const offset = ast.offset ?? 0;
  const limit = ast.limit;
  if (limit === null && offset === 0) return projected;
  const start = offset;
  const end = limit === null ? projected.length : offset + limit;
  return projected.slice(start, end);
}

Projection and ORDER BY aliases

SELECT price * 2 AS double_price ... ORDER BY double_price is valid SQL. So when sorting, first check whether the ORDER BY expression is an alias of an output column; only if it isn't do we re-evaluate it against the source row. This small detail comes up again in Chapter 7 (sorting aggregates) and Chapter 9 (JOIN).

Write statements: CREATE / DROP / INSERT

Executing write statements is more direct: find the table, evaluate expressions into values, and call methods on Table. INSERT handles both the case with a column list and the case without one (schema order), and reports a clear error when the number of columns doesn't match.

/**
 * Execution of write statements: CREATE TABLE, DROP TABLE, INSERT
 *
 * Actual data changes are handled by Table (src/table.js); this file only:
 *   1. finds the target table from the AST
 *   2. evaluates AST expressions to values
 *   3. builds the object Table.insert() expects
 *   4. returns a uniform execution result
 *
 * UPDATE / DELETE arrive in chapter 8.
 */
import { SqlError } from "../errors.js";
import { buildTableSchema, findColumn } from "../schema.js";
import { evaluate } from "./expr.js";

/** Create a uniform "command result" object. */
export function commandResult(message, { changes = 0, lastInsertRowid = null } = {}) {
  return { type: "command", message, changes, lastInsertRowid };
}

export function executeCreateTable(db, ast) {
  if (db.hasTable(ast.name)) {
    if (ast.ifNotExists) {
      return commandResult("Table " + ast.name + " already exists, skipped");
    }
    throw new SqlError("Table already exists: " + ast.name, {
      code: "SCHEMA_ERROR",
      hint: "Use CREATE TABLE IF NOT EXISTS if you do not want an error.",
    });
  }
  const schema = buildTableSchema(ast);
  db.createTable(schema);
  return commandResult(
    "Created table " + schema.name + " (" + schema.columns.length + " columns)"
  );
}

export function executeDropTable(db, ast) {
  if (!db.hasTable(ast.name)) {
    if (ast.ifExists) return commandResult("Table " + ast.name + " does not exist, skipped");
    throw new SqlError("Table does not exist: " + ast.name, {
      code: "SCHEMA_ERROR",
      hint: db.listTables().length > 0 ? "Existing tables: " + db.listTables().join(", ") : null,
    });
  }
  db.dropTable(ast.name);
  return commandResult("Dropped table " + ast.name);
}

export function executeInsert(db, ast) {
  const table = db.getTable(ast.table);

  // Decide which columns to write: use an explicit column list if given, otherwise all columns (in schema order).
  const columns = ast.columns
    ? ast.columns.map((name) => {
        const column = findColumn(table.schema, name);
        if (!column) {
          throw new SqlError("Table " + table.name + " has no column " + name, {
            code: "SCHEMA_ERROR",
            hint: "Available columns: " + table.columns.map((column) => column.name).join(", "),
          });
        }
        return column.name;
      })
    : table.columns.map((column) => column.name);

  const seen = new Set();
  for (const name of columns) {
    const key = name.toLowerCase();
    if (seen.has(key)) {
      throw new SqlError("Duplicate column in INSERT column list: " + name, { code: "SYNTAX_ERROR" });
    }
    seen.add(key);
  }

  let changes = 0;
  let lastInsertRowid = null;

  for (const valueExprs of ast.rows) {
    if (valueExprs.length !== columns.length) {
      throw new SqlError(
        "Column count and value count differ: " + columns.length + " columns, " + valueExprs.length + " values",
        { code: "SYNTAX_ERROR" }
      );
    }
    const values = {};
    for (let i = 0; i < columns.length; i++) {
      // INSERT values cannot reference columns, so the source list is empty.
      values[columns[i]] = evaluate(valueExprs[i], [], {});
    }
    const row = table.insert(values);
    changes += 1;
    lastInsertRowid = row.__rowid;
  }

  return commandResult("Inserted " + changes + " rows into " + table.name, {
    changes,
    lastInsertRowid,
  });
}

/**
 * Execute one statement and return a result object.
 *
 * Result for SELECT:
 *   { type: "select", columns: [{name, type}], rows: [[...]], rowCount }
 *
 * Results for other statements:
 *   { type: "command", message, changes, lastInsertRowid }
 *
 * @param {import("../database.js").Database} db
 * @param {object} ast
 */
export function execute(db, ast) {
  switch (ast.type) {
    case "select":
      return executeSelect(db, ast);
    case "insert":
      return executeInsert(db, ast);
    case "create_table":
      return executeCreateTable(db, ast);
    case "drop_table":
      return executeDropTable(db, ast);
    case "update":
    case "delete":
      throw new SqlError("UPDATE / DELETE is not implemented yet (arrives in chapter 8)", { code: "NOT_SUPPORTED" });
    case "begin":
    case "commit":
    case "rollback":
      throw new SqlError("Transactions are not implemented yet (added in chapter 10)", { code: "NOT_SUPPORTED" });
    default:
      throw new SqlError("Cannot execute statement: " + ast.type, { code: "INTERNAL_ERROR" });
  }
}

CLI: printing results as a table

The new bin/sql.js parses user input, executes it, and prints the results. A few details worth a look:

  • Multi-line input: if the statement isn't complete yet (say a CREATE TABLE is missing a closing paren), the REPL keeps waiting for the next line.
  • Full-width alignment: displayWidth() counts CJK characters as two cells so tables don't go crooked.
  • Error format: SqlError.format() prints a caret pointing at the error position.
  • Pipeline mode: node bin/sql.js < demo.sql executes line by line, which is handy for scripts.

/** Full-width characters such as Chinese, Japanese, and Korean take two terminal cells. */
function displayWidth(text) {
  let width = 0;
  for (const ch of text) {
    const code = ch.codePointAt(0);
    const wide =
      (code >= 0x1100 && code <= 0x115f) ||
      (code >= 0x2e80 && code <= 0xa4cf) ||
      (code >= 0xac00 && code <= 0xd7a3) ||
      (code >= 0xf900 && code <= 0xfaff) ||
      (code >= 0xfe30 && code <= 0xfe4f) ||
      (code >= 0xff00 && code <= 0xff60) ||
      (code >= 0xffe0 && code <= 0xffe6);
    width += wide ? 2 : 1;
  }
  return width;
}

function pad(text, width) {
  return text + " ".repeat(Math.max(0, width - displayWidth(text)));
}

/** Print query results as a simple table. */
function printTable(columns, rows) {
  const header = columns.map((column) => column.name);
  const cells = rows.map((row) => row.map((value) => displayValue(value)));
  const widths = header.map((name, index) =>
    Math.max(displayWidth(name), ...cells.map((row) => displayWidth(row[index] ?? "")))
  );

  const formatRow = (values) => values.map((value, index) => pad(value, widths[index])).join("  ");
  const separator = widths.map((width) => "-".repeat(width)).join("  ");

  console.log(formatRow(header));
  console.log(separator);
  for (const row of cells) console.log(formatRow(row));
  console.log("(" + rows.length + " rows)");
}

function printResult(result) {
  if (result.type === "select") {
    console.log("");
    if (outputMode === "json") {
      const objects = result.rows.map((row) => {
        const object = {};
        result.columns.forEach((column, index) => {
          object[column.name] = row[index];
        });
        return object;
      });
      console.log(JSON.stringify(objects, null, 2));
    } else {
      printTable(result.columns, result.rows);
    }
    console.log("");
    return;
  }
  console.log(result.message);
}

/** Detect an "incomplete input" syntax error; the REPL keeps waiting for more input. */
function isIncomplete(error, sql) {
  if (!(error instanceof SqlError) || error.code !== "SYNTAX_ERROR") return false;
  const message = error.message;
  if (message.includes("statement terminator") || message.includes("unterminated")) return true;
  if (error.position && error.position.offset >= sql.trimEnd().length) return true;
  return false;
}

function runStatements(statements, sql) {
  for (const ast of statements) {
    try {
      printResult(execute(db, ast));
    } catch (error) {
      printError(error, sql);
      return false;
    }
  }
  return true;
}

function runSql(sql) {
  let statements;
  try {
    statements = parseScript(sql);
  } catch (error) {
    printError(error, sql);
    return false;
  }
  if (statements.length === 0) return true;
  return runStatements(statements, sql);
}

async function runDotCommand(input) {
  const [command, ...rest] = input.split(/\s+/);
  const argument = input.slice(command.length).trim();

  switch (command.toLowerCase()) {

    case ".exit":

      } else if (db.listTables().length === 0) {

      }
      return true;
    case ".mode":
      if (argument === "table" || argument === "json") {
        outputMode = argument;
        console.log("Output mode: " + outputMode);
      } else {
        console.log("Current mode: " + outputMode + " (use .mode table or .mode json)");
      }
      return true;
    case ".tokens":
      try {
        console.log(describeTokens(argument));
      } catch (error) {
        printError(error, argument);
      }
      return true;
    case ".ast":
      try {
        console.log(JSON.stringify(parseScript(argument), null, 2));
      } catch (error) {
        printError(error, argument);
      }
      return true;
    case ".read": {
      const { readFileSync } = await import("node:fs");
      try {

/** Non-interactive mode: process stdin line by line and run a statement at its semicolon (good for scripts and CI). */
async function runPipedScript() {
  const { readFileSync } = await import("node:fs");
  const sql = readFileSync(0, "utf8");
  let buffer = "";
  for (const line of sql.split(/\r?\n/)) {
    const trimmedLine = line.trim();
    if (buffer === "" && trimmedLine.startsWith(".")) {
      const keepGoing = await runDotCommand(trimmedLine);
      if (!keepGoing) return;
      continue;
    }
    buffer = buffer === "" ? line : buffer + "\n" + line;
    if (buffer.trim() === "") {
      buffer = "";
      continue;
    }
    if (!buffer.trimEnd().endsWith(";")) continue;
    runSql(buffer.trim());
    buffer = "";
  }
  if (buffer.trim() !== "") runSql(buffer.trim());
}

async function main() {
  if (!isInteractive) {
    await runPipedScript();
    return;
  }

  const rl = createInterface({ input: process.stdin, output: process.stdout });
  printBanner();

  let buffer = "";
  rl.on("SIGINT", () => {
    if (buffer) {
      buffer = "";
      console.log("");
      return;
    }
    rl.close();
  });

  try {
    while (true) {
      const prompt = !isInteractive ? "" : buffer ? "   ... " : "sql> ";
      let line;
      try {
        line = await rl.question(prompt);
      } catch {
        break;
      }

      if (!buffer && line.trim().startsWith(".")) {
        const keepGoing = await runDotCommand(line.trim());
        if (!keepGoing) break;
        continue;
      }

      buffer = buffer ? buffer + "\n" + line : line;
      if (buffer.trim() === "") {
        buffer = "";
        continue;
      }

      const sql = buffer.trim();
      let statements;
      try {
        statements = parseScript(sql);
      } catch (error) {
        if (!sql.endsWith(";") && isIncomplete(error, sql)) {
          continue; // statement is incomplete, read the next line
        }
        printError(error, sql);
        buffer = "";
        continue;
      }

      if (statements.length > 0) {
        runStatements(statements, sql);
      }
      buffer = "";
    }
  } finally {
    rl.close();
    if (isInteractive) console.log("Goodbye!");
  }
}

main();

Chapter recap

  • A query is a pipeline: scan → filter → project → deduplicate → sort → limit.
  • A "row" at runtime is a source list, which is what lets us handle JOINs and ambiguous columns.
  • Expression evaluation has to handle three-valued logic, NULL propagation, and type conversion.
  • Database.exec() provides statement-level atomicity; the CLI makes results look good.
