Chapter 05 / Storage layer

Where data lives: schema, table, and storage backend

The parser turns CREATE TABLE into an AST, but the AST only records what the user wrote. This chapter turns it into the structures the runtime actually uses: a table's columns, constraints, and rows. We also abstract "where the data lives" behind an interface, so the same engine can run in memory or on disk.

Schema: turning the AST into rules

buildTableSchema() takes the AST of a CREATE TABLE and produces a schema. It does more than copy columns — it rejects obvious errors up front:

  • Duplicate column names (case-insensitive).
  • PRIMARY KEY declared twice.
  • A table-level constraint points at a column that doesn't exist.
  • DEFAULT isn't a constant (we only support constant defaults).

Each column looks like this:

{
  name: "price",
  type: "REAL",
  affinity: "REAL",       // decided by affinityOf in values.js
  notNull: false,
  primaryKey: false,
  unique: false,
  defaultExpr: null,
  defaultValue: 0         // precomputed constant
}

Why keep defaultExpr and also compute a defaultValue? The first is "what the user wrote" (useful for debugging and for .schema); the second is "the value actually used". This "source form + resolved form" pattern is common in compilers.

src/schema.jsJavaScript · 143 lines · step 5
/**
 * Table Schema
 *
 * The parser only reports what CREATE TABLE wrote; this file turns that into
 * the structure used at runtime and rejects obvious mistakes up front:
 *
 *   - duplicate column names (case-insensitive)
 *   - PRIMARY KEY declared twice
 *   - table-level constraint referencing a missing column
 *   - DEFAULT is not a constant (the teaching version only supports constant defaults)
 *
 * The resulting schema is a plain object that can be JSON-serialized and stored in a file (used in chapter 10).
 */
import { SqlError } from "./errors.js";
import { affinityOf, normalizeValue } from "./values.js";

/**
 * Convert a CREATE TABLE AST into a schema.
 * @param {object} ast the create_table node produced by the parser
 */
export function buildTableSchema(ast) {
  const seen = new Set();
  const columns = [];

  for (const def of ast.columns) {
    const key = def.name.toLowerCase();
    if (seen.has(key)) {
      throw new SqlError("Duplicate column name: " + def.name, { code: "SCHEMA_ERROR" });
    }
    seen.add(key);

    const affinity = affinityOf(def.type);
    const column = {
      name: def.name,
      type: def.type,
      affinity,
      notNull: Boolean(def.notNull),
      primaryKey: Boolean(def.primaryKey),
      unique: Boolean(def.unique),
      defaultExpr: def.defaultExpr,
      defaultValue: defaultValueOf(def),
    };
    if (column.primaryKey) column.notNull = true; // PRIMARY KEY implies NOT NULL
    columns.push(column);
  }

  const primaryKey = [];
  const uniques = [];

  for (const column of columns) {
    if (column.primaryKey) primaryKey.push(column.name);
    if (column.unique) uniques.push([column.name]);
  }

  for (const constraint of ast.tableConstraints ?? []) {
    for (const name of constraint.columns) {
      if (!columns.some((column) => column.name.toLowerCase() === name.toLowerCase())) {
        throw new SqlError("Constraint references a missing column: " + name, { code: "SCHEMA_ERROR" });
      }
    }
    if (constraint.kind === "primary") {
      if (primaryKey.length > 0) {
        throw new SqlError("PRIMARY KEY may only be declared once", { code: "SCHEMA_ERROR" });
      }
      for (const name of constraint.columns) {
        const column = columns.find((c) => c.name.toLowerCase() === name.toLowerCase());
        column.notNull = true;
        primaryKey.push(column.name);
      }
    } else {
      uniques.push(constraint.columns.map((name) => canonicalName(columns, name)));
    }
  }

  return {
    name: ast.name,
    columns,
    primaryKey,
    uniques,
  };
}

function defaultValueOf(def) {
  if (!def.defaultExpr) return null;
  return evaluateConstant(def.defaultExpr);
}

/** Evaluate the constant expression after DEFAULT; only literals and signs are accepted. */
export function evaluateConstant(expr) {
  if (expr.type === "literal") {
    return normalizeValue(expr.value);
  }
  if (expr.type === "unary" && (expr.op === "-" || expr.op === "+")) {
    const value = evaluateConstant(expr.expr);
    if (typeof value !== "number") {
      throw new SqlError("DEFAULT only supports numeric constants", { code: "SCHEMA_ERROR" });
    }
    return expr.op === "-" ? -value : value;
  }
  throw new SqlError("DEFAULT currently supports constants only", {
    code: "SCHEMA_ERROR",
    hint: "For example DEFAULT 0 or DEFAULT 'unknown'.",
  });
}

/** Find a column by name (case-insensitive); returns null if not found. */
export function findColumn(schema, name) {
  const key = String(name).toLowerCase();
  return schema.columns.find((column) => column.name.toLowerCase() === key) ?? null;
}

/** Map a user-written name to the canonical name in the schema. */
export function canonicalName(columns, name) {
  const key = String(name).toLowerCase();
  const column = columns.find((c) => c.name.toLowerCase() === key);
  if (!column) {
    throw new SqlError("Column does not exist: " + name, { code: "SCHEMA_ERROR" });
  }
  return column.name;
}

/** Short schema description used by the .schema command. */
export function describeSchema(schema) {
  const lines = ["CREATE TABLE " + schema.name + " ("];
  const parts = schema.columns.map((column) => {
    let part = "  " + column.name + " " + column.type;
    if (column.primaryKey) part += " PRIMARY KEY";
    if (column.notNull && !column.primaryKey) part += " NOT NULL";
    if (column.unique) part += " UNIQUE";
    if (column.defaultExpr) part += " DEFAULT " + formatConstant(column.defaultValue);
    return part;
  });
  const constraints = [];
  if (schema.primaryKey.length > 1) {
    constraints.push("  PRIMARY KEY (" + schema.primaryKey.join(", ") + ")");
  }
  return lines.concat(parts, constraints).join(",\n") + "\n);";
}

function formatConstant(value) {
  if (typeof value === "string") return "'" + value.replace(/'/g, "''") + "'";
  return String(value);
}

How is a row represented?

A row is a plain object whose keys are column names, plus a hidden __rowid: 

{ __rowid: 1, id: 1, title: "JavaScript", price: 320 }

__rowid starts at 1 and keeps increasing; deleted values are never reused. It's the stable way for UPDATE / DELETE to address a row, and the basis for adding indexes later. Tables without a primary key still have a rowid — that's SQLite's design, and it's convenient.

Constraints: the database's gatekeepers

ConstraintRuleOur implementation
NOT NULLCan't be NULLChecked on write
PRIMARY KEYUnique + not NULLTreated as a UNIQUE + NOT NULL pair
UNIQUEThe whole value set must be distinctNULLs allowed (SQL standard)
DEFAULTUsed when no value is givenComputed at CREATE TABLE time

UNIQUE checking currently scans row by row (O(n)). That gets slow with a lot of data — exactly why indexes exist; we'll come back to this in chapter 9 when we discuss JOIN performance.

Why does UNIQUE allow multiple NULLs?

Because the SQL standard defines NULL as "unknown". Two unknowns aren't guaranteed to be equal, so they shouldn't conflict. Many engineers find "a UNIQUE column can hold many NULLs" surprising the first time, but it makes sense: if you don't know someone's email, you can't claim two unknown emails are duplicates.

src/table.jsJavaScript · 183 lines · step 5
/**
 * Table: an in-memory table
 *
 * Each row is a plain object keyed by column name, plus a hidden
 * __rowid (starting at 1 and incrementing). Tables without a PRIMARY KEY still have a rowid,
 * giving UPDATE / DELETE a stable way to target a row.
 *
 * This file does three things:
 *   1. apply type affinity on write ('42' -> 42)
 *   2. apply defaults (DEFAULT)
 *   3. check constraints (NOT NULL / UNIQUE / PRIMARY KEY)
 *
 * The query itself (WHERE, ORDER BY...) lives in engine/; Table only provides scans.
 */
import { SqlError } from "./errors.js";
import { applyAffinity, groupKey, isNull, normalizeValue } from "./values.js";

export class Table {
  /**
   * @param {object} schema produced by schema.js
   * @param {{rows?: object[], nextRowid?: number}} [data]
   */
  constructor(schema, data = {}) {
    this.schema = schema;
    this.rows = new Map();
    this.nextRowid = data.nextRowid ?? 1;
    for (const row of data.rows ?? []) {
      const copy = { ...row };
      this.rows.set(copy.__rowid, copy);
      if (copy.__rowid >= this.nextRowid) this.nextRowid = copy.__rowid + 1;
    }
  }

  get name() {
    return this.schema.name;
  }

  get columns() {
    return this.schema.columns;
  }

  /** Return all rows (read-only walk; the executor does not modify these objects). */
  all() {
    return [...this.rows.values()];
  }

  size() {
    return this.rows.size;
  }

  get(rowid) {
    return this.rows.get(rowid) ?? null;
  }

  /**
   * Insert a row.
   * @param {Record<string, unknown>} values column name -> value (may be partial)
   * @returns {object} the row actually written (including __rowid)
   */
  insert(values) {
    const row = this.buildRow(values, null);
    this.checkConstraints(row, null);
    row.__rowid = this.nextRowid;
    this.nextRowid += 1;
    this.rows.set(row.__rowid, row);
    return row;
  }

  /**
   * Update a row. values only needs to contain the columns to change.
   * @param {number} rowid
   * @param {Record<string, unknown>} values
   */
  update(rowid, values) {
    const existing = this.rows.get(rowid);
    if (!existing) {
      throw new SqlError("Row to update not found (rowid = " + rowid + ")", { code: "INTERNAL_ERROR" });
    }
    const candidate = this.buildRow(values, existing);
    this.checkConstraints(candidate, rowid);
    candidate.__rowid = rowid;
    this.rows.set(rowid, candidate);
    return candidate;
  }

  /** Delete a row; returns whether anything was actually deleted. */
  delete(rowid) {
    return this.rows.delete(rowid);
  }

  /**
   * Turn "values supplied by the user" into "the row that is actually stored":
   * - columns not supplied use DEFAULT, otherwise NULL
   * - all values go through type affinity conversion
   */
  buildRow(values, existingRow) {
    const provided = new Map();
    for (const [key, value] of Object.entries(values ?? {})) {
      provided.set(key.toLowerCase(), value);
    }

    const row = {};
    for (const column of this.schema.columns) {
      const key = column.name.toLowerCase();
      let value;
      if (provided.has(key)) {
        value = provided.get(key);
      } else if (existingRow) {
        value = existingRow[column.name];
      } else {
        value = column.defaultValue;
      }
      row[column.name] = applyAffinity(value, column.affinity);
    }

    // Unknown columns must be reported explicitly, not silently ignored.
    for (const key of provided.keys()) {
      if (!this.schema.columns.some((column) => column.name.toLowerCase() === key)) {
        throw new SqlError("Table " + this.schema.name + " has no column " + key, {
          code: "SCHEMA_ERROR",
          hint: "Available columns: " + this.schema.columns.map((c) => c.name).join(", "),
        });
      }
    }

    return row;
  }

  /**
   * Check constraints. ignoreRowid is used by UPDATE to exclude the row itself.
   */
  checkConstraints(row, ignoreRowid) {
    for (const column of this.schema.columns) {
      if (column.notNull && isNull(row[column.name])) {
        throw new SqlError("Column " + column.name + " cannot be NULL (NOT NULL constraint)", {
          code: "CONSTRAINT_ERROR",
        });
      }
    }

    const uniqueSets = [];
    if (this.schema.primaryKey.length > 0) {
      uniqueSets.push({ columns: this.schema.primaryKey, label: "PRIMARY KEY" });
    }
    for (const unique of this.schema.uniques) {
      uniqueSets.push({ columns: unique, label: "UNIQUE" });
    }

    for (const { columns, label } of uniqueSets) {
      const values = columns.map((name) => row[name]);
      // UNIQUE allows multiple NULLs (SQL standard); PRIMARY KEY is already covered by NOT NULL.
      if (values.some((value) => isNull(value))) continue;
      const key = groupKey(values);
      for (const other of this.rows.values()) {
        if (other.__rowid === ignoreRowid) continue;
        const otherValues = columns.map((name) => other[name]);
        if (otherValues.some((value) => isNull(value))) continue;
        if (groupKey(otherValues) === key) {
          throw new SqlError(
            "Violates " + label + " constraint: (" + columns.join(", ") + ") = (" + values.map(formatValue).join(", ") + ") already exists",
            { code: "CONSTRAINT_ERROR" }
          );
        }
      }
    }
  }

  /** Serialize to plain data for storage or transaction snapshots. */
  toJSON() {
    return {
      schema: this.schema,
      nextRowid: this.nextRowid,
      rows: this.all(),
    };
  }
}

function formatValue(value) {
  const normalized = normalizeValue(value);
  if (normalized === null) return "NULL";
  if (typeof normalized === "string") return "'" + normalized + "'";
  return String(normalized);
}

Abstract "where data lives" into an interface

Database shouldn't know whether it runs in memory or on disk. So we define a tiny interface: 

store.load()          // return the last saved snapshot, or null
store.save(snapshot)  // write the whole database out
store.close()         // clean up

MemoryStore just keeps the snapshot in a variable. Chapter 10's DiskStore uses exactly the same interface to split the snapshot into pages and write them to a file. Defining the interface first and swapping the implementation later keeps tests fast (in memory) while production still persists.

src/storage/memory.jsJavaScript · 31 lines · step 5
/**
 * MemoryStore: a storage backend that lives only in memory.
 *
 * Chapter 10 adds a DiskStore that wires the same interface to real files:
 *
 *   load()         -> last saved snapshot (null if never saved)
 *   save(snapshot) -> write the whole database out
 *   close()        -> close
 *
 * With this interface, Database does not need to know whether it runs in memory or on disk.
 */
export class MemoryStore {
  constructor() {
    this.snapshot = null;
  }

  /** @returns {object|null} the last saved snapshot */
  load() {
    return this.snapshot;
  }

  /** @param {object} snapshot */
  save(snapshot) {
    // Deep copy so later database changes do not affect the "saved" version.
    this.snapshot = structuredClone(snapshot);
  }

  close() {
    // The in-memory version has nothing to close.
  }
}

Database: the public facade

Database collects all tables and is responsible for creating and dropping tables, exporting snapshots, and restoring from them. It deliberately contains no SQL parsing or query execution — that's the next chapter. The facade's benefit: users have a single entry point, and every internal module can be tested on its own.

src/database.jsJavaScript · 114 lines · step 5
/**
 * Database: the facade of the whole engine
 *
 * It keeps track of "which tables exist" and is responsible for:
 *   - creating / dropping tables
 *   - loading from the storage backend and writing snapshots back to it
 *   - later (chapter 6) providing exec() to run SQL
 *
 * All database state lives in memory: it is read from store.load() on open, and after writes
 * store.save() is called to persist it. This is a teaching simplification, but the interface matches a real database
 * exactly: the storage layer is replaceable (MemoryStore / DiskStore).
 */
import { MemoryStore } from "./storage/memory.js";
import { Table } from "./table.js";
import { SqlError } from "./errors.js";

/** Version of the current snapshot format; lets us detect format changes later. */
export const SNAPSHOT_VERSION = 1;

export class Database {
  /**
   * @param {{store?: {load:Function, save:Function, close?:Function}}} [options]
   */
  constructor(options = {}) {
    this.store = options.store ?? new MemoryStore();
    /** @type {Map<string, Table>} key is the lowercase table name */
    this.tables = new Map();
    this.closed = false;
  }

  /**
   * Open a database: create a Database and load existing data from the store.
   * @param {{load:Function, save:Function, close?:Function}} [store]
   */
  static open(store = new MemoryStore()) {
    const db = new Database({ store });
    const snapshot = store.load();
    if (snapshot) db.loadSnapshot(snapshot);
    return db;
  }

  /** Find a table by name (case-insensitive); returns undefined if not found. */
  findTable(name) {
    return this.tables.get(String(name).toLowerCase());
  }

  /** Find a table by name; throws if not found. */
  getTable(name) {
    const table = this.findTable(name);
    if (!table) {
      throw new SqlError("Table does not exist: " + name, {
        code: "SCHEMA_ERROR",
        hint: this.listTables().length > 0 ? "Existing tables: " + this.listTables().join(", ") : "There are no tables yet",
      });
    }
    return table;
  }

  hasTable(name) {
    return this.tables.has(String(name).toLowerCase());
  }

  listTables() {
    return [...this.tables.values()].map((table) => table.name);
  }

  /** Create a table (the schema is produced by schema.js). */
  createTable(schema) {
    if (this.hasTable(schema.name)) {
      throw new SqlError("Table already exists: " + schema.name, { code: "SCHEMA_ERROR" });
    }
    const table = new Table(schema);
    this.tables.set(schema.name.toLowerCase(), table);
    return table;
  }

  /** Drop a table; returns whether anything was actually dropped. */
  dropTable(name) {
    return this.tables.delete(String(name).toLowerCase());
  }

  /** Export a snapshot of the whole database (plain data, JSON-serializable). */
  snapshot() {
    return {
      version: SNAPSHOT_VERSION,
      tables: [...this.tables.values()].map((table) => table.toJSON()),
    };
  }

  /** Restore the whole database from a snapshot. */
  loadSnapshot(snapshot) {
    if (!snapshot || !Array.isArray(snapshot.tables)) {
      throw new SqlError("Invalid database file format", { code: "STORAGE_ERROR" });
    }
    this.tables.clear();
    for (const data of snapshot.tables) {
      const table = new Table(data.schema, { rows: data.rows, nextRowid: data.nextRowid });
      this.tables.set(table.name.toLowerCase(), table);
    }
  }

  /** Write the current state back to the storage backend. */
  save() {
    this.store.save(this.snapshot());
  }

  /** Close the database: save first, then close the store. */
  close() {
    if (this.closed) return;
    this.save();
    this.store.close?.();
    this.closed = true;
  }
}

Snapshots: a database you can pass around

snapshot() returns a plain JSON-serializable object; loadSnapshot() rebuilds the whole database from one. This isn't just for persistence — it's also the basis for transactions: take a snapshot at BEGIN and restore it at ROLLBACK. Chapter 10 shows how this design carries all the way to disk and the journal.

Chapter recap

  • The schema is the AST's runtime form; it rejects duplicate columns and similar errors up front.
  • Each row is a plain object plus __rowid; constraints are checked in Table.
  • The storage backend has only three methods — load / save / close — so memory and disk are interchangeable.
  • Snapshots are both the save format and the basis for transaction rollback.

Exercises

  1. Add a CHECK (price >= 0) constraint: the parser must support it, the schema must preserve it, and Table must enforce it.
  2. Change UNIQUE checking from a linear scan to a Set cache (remember to keep it in sync on update).
  3. Make snapshot() also record which database version this is, and check it on load.
